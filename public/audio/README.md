# English pronunciation recordings

These short, locally generated English word recordings are a fallback for browsers without an installed English speech voice. Safari's native English voice is preferred when available. The recordings require no third-party service or account.

Generated with eSpeak NG, en-us voice, rate 130, pitch 53; 22,050 Hz mono 16-bit PCM WAV with 120 ms trailing silence. The synthesizer was run as a development tool and is not distributed with this game. Generated audio output is not eSpeak program code; eSpeak's GPL license does not require synthesized output to be GPL. Source tool: https://github.com/espeak-ng/espeak-ng; Emscripten build: @echogarden/espeak-ng-emscripten 0.3.5.

To add a vocabulary recording, place an original or licensed WAV/MP3/M4A here and set the vocabulary item's `audio` field to its relative path. A new item without an audio file still uses the browser's English speech synthesis voice.
